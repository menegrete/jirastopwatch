# Keyboard shortcuts

## Main window

All shortcuts act on the currently selected row.

| Shortcut | Action |
|---|---|
| `Ctrl+Up` | Select the previous row |
| `Ctrl+Down` | Select the next row |
| `Ctrl+N` | Add a new issue row |
| `Ctrl+Delete` | Remove the selected row |
| `Ctrl+I` | Focus the selected row's issue-key field |
| `Ctrl+C` | Copy the selected row's issue key |
| `Ctrl+V` | Paste an issue key (or issue URL) into the selected row |
| `Ctrl+P` | Start/stop the selected row's timer |
| `Ctrl+E` | Edit the selected row's elapsed time |
| `Ctrl+R` | Reset the selected row's timer |
| `Ctrl+L` | Post a worklog for the selected row |
| `Ctrl+O` | Open the selected issue in your browser |

Double-clicking a row's time pill also opens the edit-time dialog.

## Worklog dialog

| Shortcut | Action |
|---|---|
| `Ctrl+Enter` (in the comment field) | Submit the worklog |
| `Enter` (in the Set To / Reduce By fields) | Submit the worklog |
| `Alt+B` | Submit |
| `Alt+V` | Save for later |
| `Enter` | Submit (default button) |
| `Esc` | Cancel |

## Edit time / Settings dialogs

`Enter` confirms (OK/Submit) and `Esc` cancels, as usual for Windows dialogs.

## Mini timer view

The mini timer view has no keyboard shortcuts — it's operated with the mouse (drag to move, click to pause/resume, hover to reveal copy/open buttons, double-click the background to restore the main window).
